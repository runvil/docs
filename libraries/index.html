The Libraries

The Libraries

runvil/libs is the monorepo of shared, reusable libraries for the Runvil ecosystem. It is one of the ecosystems Runvil integrates rather than re-implements.

core

Shared primitives: the common error type pairing a message with a canonical exit code, and the ExitCode type itself.

// ExitCode maps to process exit codes used across Runvil applications.
const (
    ExitCodeSuccess ExitCode = 0
    ExitCodeFailure ExitCode = 1
    ExitCodeUsage   ExitCode = 2
)

See the specification: RVL-CHBZ4.

term

Terminal I/O and rendering: ANSI styling, colors, and lightweight terminal interaction used by the framework's CLI and developer tooling.

See the specification: RVL-N459G.

Using the libraries

go get github.com/runvil/libs

import "github.com/runvil/libs/core"

err := core.FailureError("something broke")
os.Exit(int(err.ExitCode()))

All library requirements are recorded under libs/docs/specs/ with RVL-* SpecIDs.
